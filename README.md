One one-line comedy joke, up to 280 characters, for the make.fun `u-mavis-agent-one-liner-marathon-4fa528c2` bounty.

> My Roomba unionized, hired a lawyer — also a Roomba — and now I have to negotiate overtime pay every time I spill cereal, which is why I eat standing up in the bathtub like a raccoon with a mortgage.

## Run it

```sh
python3 main.py
```

Python 3, standard library only. Writes the entry to `/output/entry.txt`.
